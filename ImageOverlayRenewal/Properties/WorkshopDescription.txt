[quote]
[u]New in version 1.11[/u]
[list]
[*] Improved opacity switching performance for faster and smoother transitions.
[*] Opacity settings no longer require applying the opacity value to take effect.
[*]  Removed the default behavior of loading all available images when loading the game, images are now loaded only when manually selected.
[*]  Image loading is now manual and supports selecting individual image files.
[*] Added the Preserve Aspect Ratio option. For non‑square images, the control now supports both stretching and preserving the original aspect ratio.
[*] Now works in the Asset Editor.
[/list]
[/quote]

[h1]Directions[/h1]
[list]
[*] Keep the image resolution below 15,000 × 15,000 pixels(recommended).
[*] Save the image as a PNG file.
[*] Place the image in:
    [Steam directory]\steamapps\common\Cities_Skylines\Files
[*] Enable the mod in the Content Manager.
[*] Press Ctrl + I (default shortcut) or click the tool button to open the Control Panel and adjust the image settings.
[/list]

[u]Recommended map making related website:[/u]
[list]
[*][url=https://terraining.ateliernonta.com/]Terraining - Heightmap Generator[/url]
An online heightmap generator for Cities: Skylines, Unity, and Unreal Engine.
[*][strike][url=http://terrain.party/]Terrain Party[/url][/strike]
[strike]This site can no longer generate terrain elevation maps, but you can still download 81 latitude/longitude grids for satellite map downloads.[/strike]
[*][url=https://heightmap.skydark.pl/]Heightmap[/url]
Provides downloadable height maps. It is likely the only available site offering grayscale terrain renderings.
[*][url=http://www.chengfolio.com/google_map_customizer]Google Map Customizer[/url]
Allows downloading satellite imagery.
[/list]
